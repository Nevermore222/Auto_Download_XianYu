# 卖家流程与夸克上传说明

## 一、您的操作流程（用户多手机端，您用网页）

1. **客户（一般手机端）** 在闲鱼等渠道发来需求：要下载某条视频。
2. **您** 在手机或电脑上打开 **自己搭建的服务器网页**（即本项目的「卖家工作台」），输入客户要的视频链接。
3. **查询价格**：点击「查询价格（报给客户）」，页面显示该视频的时长、分辨率与价格，您把价格报给客户。
4. **客户下单**：客户确认并下单（在闲鱼付款或按您们约定方式）。
5. **提交并处理**：您在同一页面点击「提交并处理（下载→上传夸克→生成链接）」。
6. **服务器自动完成**：
   - 在您**自己的服务器**上解析该视频；
   - 下载到服务器本地；
   - 上传到**您的夸克网盘**；
   - 生成夸克分享链接。
7. **发给客户**：页面显示夸克链接后，您点击「复制链接」，把链接发给客户（如通过闲鱼/微信），客户用夸克打开即可下载。

全程您只需：**输入链接 → 查价 → 客户下单后点「提交并处理」→ 复制链接发给客户**。解析、下载、上传、生成链接均在您服务器上自动完成。

---

## 二、如何启动「卖家工作台」网页

1. 在服务器上配置好 `config/config.yaml`（夸克 Cookie、下载目录等），见 `docs/夸克Cookie获取.md`。
2. 先启动**下载系统**（执行下载与上传的接口）：
   ```bash
   python -m src.system.server
   ```
   默认端口 8766。
3. 再启动**店铺/工作台**（提供网页与 API）：
   ```bash
   python -m src.store.app
   ```
   默认端口 8770。
4. 浏览器访问 **http://您的服务器IP:8770**（或您用 Nginx 绑定的域名），即可使用卖家工作台。手机浏览器访问同一地址即可在手机上操作。

## 三、夸克上传实现说明

本项目中**上传到夸克网盘并生成分享链接**的逻辑在 **`src/quark/client.py`**，实现方式与常见博客中的思路一致：

- **预上传**：调用夸克 `/file/upload/pre` 获取 task_id、upload_id、bucket、obj_key 等；
- **秒传**：可选提交文件 MD5/SHA1，若服务器已有相同文件则直接完成；
- **分片上传**：大文件按约 1MB 分片，逐片请求 `/file/upload/auth` 获取签名后 PUT 到 OSS；
- **提交与完成**：所有分片上传后调用完成接口，再调用 `/file/upload/finish` 得到文件 fid；
- **分享链接**：用 fid 调用分享接口（含异步任务轮询），得到夸克分享链接。

您提到的参考文章：  
**夸克网盘上传接口实现**  
https://blog.csdn.net/fghjbjhgb/article/details/145800274  

若该文章中有接口路径或参数与当前实现不一致，可对照该文调整 `src/quark/client.py` 中的请求地址或请求体；当前实现已支持小文件整块上传与大文件分片上传，以及创建分享链接并轮询获取最终链接。

## 四、简要总结

| 步骤 | 您做的 | 系统做的 |
|------|--------|----------|
| 1 | 在网页输入客户要的视频链接 | — |
| 2 | 点击「查询价格」，把价格报给客户 | 解析链接，返回时长、分辨率与价格 |
| 3 | 客户下单后，点击「提交并处理」 | 在服务器上解析视频、下载到本地、上传到您的夸克、生成分享链接 |
| 4 | 复制页面上的夸克链接，发给客户 | — |

用户多在手机端沟通，您用同一网页在电脑或手机浏览器中即可完成查价、提交处理与复制链接。
