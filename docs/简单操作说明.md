# 视频代下载 - 简单操作说明

---

## 推荐流程：您用网页、客户多手机端

1. 您在**自己服务器**上打开**卖家工作台**网页（见下方「启动卖家工作台」）。
2. 客户（一般手机）发来要下载的视频链接 → 您把链接**输入到网页**里，点 **「查询价格」**，把价格报给客户。
3. 客户下单后，您在同一网页点 **「提交并处理」** → 服务器会自动：解析视频、下载到您服务器、上传到您的夸克网盘、生成夸克链接。
4. 页面出现**夸克链接**后，您点 **「复制链接」**，发给客户即可。客户用夸克打开就能下载。

**卖家工作台支持手机浏览器**，您用手机打开同一网页也能完成上述操作。详细流程见 **`docs/卖家流程与夸克上传说明.md`**。

---

## 您（卖家）每天怎么操作

### 第一步：改一次配置（只做一次）

1. 用记事本打开 **`config/config.yaml`**，填好 **夸克 Cookie**（见 `docs/夸克Cookie获取.md`）。
2. 若要用核销码发给客户用桌面下载器，再改 **`desktop_app/config.json`** 里的 `code_secret`（见下方「生成核销码」）。

### 第二步：启动卖家工作台（每次用之前）

1. 先双击 **`scripts\run_system.bat`**（下载与上传服务）。
2. 再双击 **`scripts\run_store.bat`**（卖家工作台网页）。
3. 浏览器打开 **http://127.0.0.1:8770**（本机）或 **http://您的服务器IP:8770**（手机也可打开同一地址）。

### 第三步：生成核销码（仅当客户要用桌面下载器时）

1. 打开 **命令提示符**（Win+R 输入 `cmd` 回车）。
2. 输入下面两行（每行回车一次），第二行的 `10` 表示 10 次，可改成 5、20 等：

   ```text
   cd /d D:\auto_download
   python -m desktop_app.generate_codes 10
   ```

3. 屏幕上会出现一串 **核销码**（像 `WDxxxxxxxx`），**整串复制**发给客户即可。

### 第四步：把链接或软件发给客户

- **方式 A（推荐）**：把您的 **自助网站地址** 发给客户（例如 `http://你的服务器:8770`），客户打开网页输入视频链接就能下单，您不用一个个发核销码。
- **方式 B**：客户要用「下载器软件」时，把 **核销码**（上面第三步生成的）发给他，并告诉他：  
  「下载器里先填核销码点绑定，再填视频链接下载，每次成功下载会扣 1 次，用完再问我要新码。」

---

## 客户（用自助网站）怎么操作

1. 打开您发的 **网站链接**。
2. 在框里 **粘贴视频链接**（B 站、抖音等）。
3. 点 **「查询价格」** 看价格，再点 **「提交订单」**。
4. 等一会儿，页面出现 **夸克网盘链接**，点 **「复制链接」**，用夸克打开即可下载。

---

## 客户（用下载器软件）怎么操作

1. 打开您发给他的 **「视频收费下载」** 软件。
2. 在 **「核销码」** 框里粘贴您发的核销码，点 **「绑定核销码」**。
3. 在 **「视频链接」** 框里粘贴 B 站/抖音链接，点 **「解析视频」**。
4. 选好 **保存位置**，点 **「开始下载」**。  
   每成功下载 1 条会自动扣 1 次，次数用完后需要再向您要新核销码。

---

## 发给客户的下载器（做成 exe 一次即可）

1. 在 **命令提示符** 里执行（在项目目录下）：

   ```text
   pip install pyinstaller
   pyinstaller desktop_app/build.spec
   ```

2. 打开 **`dist`** 文件夹，把里面的 **「视频收费下载.exe」** 和 **`config.json`** 一起打包（压缩成 zip）发给客户。
3. 提醒客户：电脑需要先安装 **FFmpeg**（百度搜「FFmpeg 下载」安装并加入 PATH）。

---

## 一句话总结

- **您**：配置好 Cookie 和 `code_secret` → 需要时运行 `python -m desktop_app.generate_codes 10` 拿核销码发给客户 → 客户在下载器里绑定后按次下载，用完失效。  
- **客户**：拿到核销码 → 在下载器里「绑定核销码」→ 填视频链接 → 「开始下载」即可，**下载器里不用再付钱**，只看剩余次数。
