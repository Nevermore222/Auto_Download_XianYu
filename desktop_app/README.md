# 视频收费下载 - 电脑端桌面应用

用户安装本软件后，**先绑定您发放的核销码**，再输入视频网址即可按次下载到本地。**下载器内不单独收费**，费用通过核销码次数控制：您给客户一个核销码（如 10 次），客户在应用内绑定后，每成功下载 1 条视频自动核销 1 次，次数用尽后该码自动失效。**优先适配 B 站**，支持抖音等 yt-dlp 支持的平台。

## 运行方式

### 方式一：直接运行（开发/测试）

在**项目根目录** `D:\auto_download` 下：

1. 安装桌面端依赖：
   ```bash
   pip install -r requirements-desktop.txt
   ```
2. 启动应用：
   ```bash
   python -m desktop_app
   ```

### 方式二：打包成 exe（发给用户）

1. 安装 PyInstaller：
   ```bash
   pip install pyinstaller
   ```
2. 在项目根目录执行：
   ```bash
   pyinstaller desktop_app/build.spec
   ```
3. 打包完成后，在 `dist/` 目录下会生成 **视频收费下载.exe**。将 `desktop_app/config.json` 复制到 `dist/` 中与 exe 同目录，用户即可使用。
4. 用户需自行安装 **FFmpeg** 并加入系统 PATH（用于合并音视频），否则部分视频可能无法合并为 mp4。

## 使用说明（客户侧）

1. 打开软件，在 **「核销码」** 处输入您发给他的核销码，点击 **绑定核销码**。
2. 绑定成功后界面会显示「当前码: xxx  剩余 N 次」。
3. 在「视频链接」输入框中粘贴 B 站/抖音等视频链接，点击 **解析视频**。
4. 选择保存目录后，点击 **开始下载**。每成功下载 1 条，自动核销 1 次；次数用尽后需重新向您索取新核销码。

## 您如何生成核销码（发给客户）

1. 在 **config.json** 中配置 **code_secret**（与客户下载器内的 config 保持一致，用于核销码签名，请设为随机字符串并勿泄露）。
2. 在项目根目录执行：
   ```bash
   python -m desktop_app.generate_codes 10
   ```
   其中 `10` 表示该码可下载 10 次，可改为任意 1～65535。
3. 终端会打印一枚核销码，将整串码发给客户即可；客户在下载器中绑定后即可按次下载，次数用尽后自动失效。

也可不传参数，运行后按提示输入次数：
```bash
python -m desktop_app.generate_codes
```

## 配置文件 config.json

编辑与 exe 同目录的 `config.json`（或开发时编辑 `desktop_app/config.json`）：

- **code_secret**：核销码签名密钥，生成核销码的脚本与客户下载器必须使用同一密钥；请设为随机字符串并勿泄露。
- **default_save_dir**：默认保存路径，留空则使用系统「视频」文件夹。
- **pricing**：仅作您自己参考（如按次数定价），下载器内不展示、不收费。

修改后重启软件生效。
