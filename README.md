# 闲鱼视频代下载业务系统

多网站视频代下载：客户提供视频链接 → 下载 → 上传夸克云盘 → 返回云盘链接给客户。

**主流用法**：使用 **卖家工作台**（Web 页面）：您输入客户要的视频链接（支持多条）→ 查价报给客户 → 客户下单后点击「提交并处理」→ 服务器自动解析、下载、上传夸克并生成链接，您复制链接发给客户即可。支持手机浏览器操作。详见 [卖家工作台（推荐）](#卖家工作台推荐)。

| 项目 | 说明 |
|------|------|
| **闲鱼账号** | 用于接待客户、收发消息的闲鱼卖家账号。 |
| **接入方式** | 闲鱼无官方个人卖家 API，可选：<br>• **方案 A**：使用开源/第三方「闲鱼 API」类项目（如 XianYuApis、闲鱼自动销售系统）做消息收发，本系统的「助手」通过其 Webhook/API 接收「客户发来的链接」并回发「云盘链接」；<br>• **方案 B**：暂时人工：客户发链接后您复制到本系统 Web 页或 API，系统处理完再把云盘链接复制回闲鱼发给客户。 |

```
[闲鱼客户] ←→ [闲鱼平台] ←→ [您] ←→ [卖家工作台 Web] ←→ [下载与上传系统]
                                ↑              ↑
                                |              +-- 输入链接、查价、提交处理
                                |              +-- 返回夸克分享链接，您复制发给客户
                                |
                          [您在浏览器打开 8770，可电脑或手机]
```

- **卖家工作台**（推荐）：您打开网页，输入客户要的视频链接（支持多条）→ 查价 → 客户下单后点击「提交并处理」→ 系统自动下载并上传夸克，生成一个链接，您复制发给客户。
- **下载与上传系统**：解析链接 → yt-dlp 下载 → 上传夸克云盘 → 返回云盘分享链接。
- **助手**（可选）：另提供 API 与简单页，供闲鱼自动化或人工复制链接时调用。

## 快速开始（卖家工作台）

1. 安装依赖：`pip install -r requirements.txt`
2. 配置 `config/config.yaml`（下载目录、**夸克 Cookie** 等），Cookie 获取见 `docs/夸克Cookie获取.md`
3. **先启动下载系统**：`python -m src.system.server` 或双击 `scripts\run_system.bat`（端口 8766）
4. **再启动卖家工作台**：`python -m src.store.app` 或双击 `scripts\run_store.bat`（端口 8770）
5. 浏览器打开 **http://127.0.0.1:8770**，在文本框内粘贴客户要的视频链接（每行一条），点「查询价格」报给客户，客户下单后点「提交并处理」，等待完成后复制夸克链接发给客户

更多说明见 [卖家工作台（推荐）](#卖家工作台推荐)、[配置与运行](#配置与运行) 和 [测试](#测试)。

## 卖家工作台（推荐）

卖家工作台是一个 **Web 页面**，是当前推荐的**主流用法**：您（卖家）在浏览器中输入客户要的视频链接，先查价报给客户，客户下单后一键提交，由服务器自动完成「解析 → 下载到本机 → 上传到您的夸克网盘 → 生成一个分享链接」，您只需复制该链接发给客户即可。支持**多条链接**批量处理，且支持**手机浏览器**操作。

### 启动方式

1. 确保已配置 `config/config.yaml`（尤其是 **quark.cookie**），见 `docs/夸克Cookie获取.md`。
2. **先启动下载系统**（执行下载与上传的后端）：
   ```bash
   python -m src.system.server
   ```
   或双击 `scripts\run_system.bat`，默认端口 **8766**。
3. **再启动卖家工作台**（提供网页与 API）：
   ```bash
   python -m src.store.app
   ```
   或双击 `scripts\run_store.bat`，默认端口 **8770**。
4. 浏览器访问 **http://127.0.0.1:8770**（本机）或 **http://您的服务器IP:8770**（局域网/公网）。

### 使用流程

| 步骤 | 您做的 | 系统做的 |
|------|--------|----------|
| 1 | 在「客户视频链接」文本框内粘贴链接（**每行一条**，可多条） | — |
| 2 | 点击 **「查询价格（报给客户）」** | 解析每条链接，显示标题、时长、分辨率、单价及**合计总价** |
| 3 | 把总价（或明细）报给客户，客户确认下单 | — |
| 4 | 点击 **「提交并处理（下载→上传夸克→生成一个链接）」** | 在服务器上：逐条下载 → 上传到夸克**同一批次文件夹** → 生成**一个**夸克分享链接 |
| 5 | 页面显示「处理完成」后，点击 **「复制链接」**，将链接发给客户（闲鱼/微信等） | — |

客户打开该链接即可看到本批全部视频（一个夸克文件夹），无需您逐个发多条链接。

### 多条链接与批量

- **输入**：文本框支持**多行**，每行一条 B 站/抖音等链接，可一次粘贴客户发来的多条。
- **报价**：点击「查询价格」后，页面展示**每条**的标题、时长、分辨率、单价，以及**合计总价**，便于您一次性报价。
- **处理**：点击「提交并处理」后，系统会：
  - 将本批所有视频**下载到服务器同一批次目录**（如 `downloads/batch_xxx/`）；
  - 在您的夸克网盘里**新建一个批次文件夹**（如「视频批次_xxxxxxxx」）；
  - 将本批视频**全部上传到该文件夹**；
  - 对该文件夹生成**一个分享链接**。
- 您只需把这一**一个链接**发给客户，客户打开后即为本批全部视频。

### 进度显示

提交后，页面会轮询并显示当前步骤，例如：

- 正在下载第 1/3 条…
- 第 1 条下载完成
- 正在下载第 2/3 条…
- …
- 正在创建夸克文件夹…
- 正在上传到夸克（共 3 个文件）…
- 正在生成分享链接…
- 处理完成

便于您了解处理到哪一步，无需反复刷新。

### 定价配置

总价按每条视频的**时长 + 分辨率**计算，规则在 `config/config.yaml` 的 **store.pricing** 中配置，例如：

```yaml
store:
  port: 8770
  pricing:
    duration:                          # 按时长（分钟）
      - { max_minutes: 1, price: 0.5 }
      - { max_minutes: 5, price: 1.5 }
      - { max_minutes: 30, price: 3 }
      - { max_minutes: 9999, price: 6 }
    resolution_add:                    # 分辨率加价（元）
      - { min_height: 721, add: 0.5 }
      - { min_height: 1081, add: 1 }
```

修改后重启 `src.store.app` 生效。

### 手机使用

卖家工作台页面已做**移动端适配**，您可在手机浏览器中打开同一地址（如 `http://您的服务器IP:8770`），完成查价、提交、复制链接等操作，方便在闲鱼/微信沟通时直接用手机处理。

### 公网部署

若希望在外网或手机 4G 下访问，可将本系统部署到云服务器，并开放 **8770** 端口（或通过 Nginx 等反向代理到 8770），然后使用 **http://您的域名或公网IP:8770** 访问。注意同时保证 **8766** 端口对本地或内网可达（store 会请求本机 8766 执行下载与上传）。

## 配置与运行

1. **配置文件**：复制 `config/config.yaml.example` 为 `config/config.yaml`，按需修改；夸克 Cookie 见 `docs/夸克Cookie获取.md`。
2. **安装依赖**：在项目根目录执行  
   `pip install -r requirements.txt`  
   并确保已安装 **FFmpeg**（用于合并音视频）。
3. **启动顺序（卖家工作台）**：  
   - 先启动「下载系统」：`python -m src.system.server`（或 `scripts\run_system.bat`），默认端口 **8766**。  
   - 再启动「卖家工作台」：`python -m src.store.app`（或 `scripts\run_store.bat`），默认端口 **8770**。  
   - 浏览器访问 **http://127.0.0.1:8770** 使用。
4. **其他服务**（可选）：  
   - **助手**：`python -m src.assistant.app`（端口 8765），提供简单 Web 页与 API，适合对接闲鱼或人工复制链接。  
   - **客户自助网站**：与卖家工作台为同一应用（store），若将 8770 地址发给客户，客户也可自助输入链接查价、下单并获取夸克链接。

## 负载均衡

- **单机**：当前自助网站与助手均单进程即可运行，订单在内存中排队处理。
- **多实例**：若需多机/多进程分担请求，可在前方加 **Nginx/云负载均衡** 做 HTTP 分流；注意同一订单的「提交」与「轮询状态」需落在同一实例（可用会话保持 / sticky session），或后续将任务状态存 Redis，多实例共享状态。

## 关于夸克上传

夸克网盘无官方开放 API，当前 `src/quark/client.py` 中的上传与分享接口为基于社区逆向的示例实现，**实际请求格式可能随夸克网页版更新而变动**。若上传失败，可：

- 按 `docs/夸克Cookie获取.md` 确认 Cookie 有效；
- 参考开源项目 [quark-auto-save](https://github.com/Cp0204/quark-auto-save) 等更新接口或改用其 API；
- 暂时使用「仅下载」模式，手动将 `downloads/` 下文件上传到夸克并复制链接给客户。
