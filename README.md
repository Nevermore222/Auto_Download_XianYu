# 闲鱼视频代下载业务系统

多网站视频代下载：客户提供视频链接 → 下载 → 上传夸克云盘 → 返回云盘链接给客户。

---

## 需要您提前准备的事项

### 1. 闲鱼侧（助手对接）

| 项目 | 说明 |
|------|------|
| **闲鱼账号** | 用于接待客户、收发消息的闲鱼卖家账号。 |
| **接入方式** | 闲鱼无官方个人卖家 API，可选：<br>• **方案 A**：使用开源/第三方「闲鱼 API」类项目（如 XianYuApis、闲鱼自动销售系统）做消息收发，本系统的「助手」通过其 Webhook/API 接收「客户发来的链接」并回发「云盘链接」；<br>• **方案 B**：暂时人工：客户发链接后您复制到本系统 Web 页或 API，系统处理完再把云盘链接复制回闲鱼发给客户。 |
| **如需自动回复** | 若用第三方工具，需在其后台配置「关键词→自动回复」或「收到链接→调用本系统接口」。 |

当前仓库内的「助手」以 **HTTP API + 简单 Web 管理页** 方式提供，方便您先跑通流程，再替换为闲鱼实际消息源（Webhook 回调等）。

**客户自助网站（推荐）**：闲鱼客户询问时，直接发 **自助网站链接**，客户打开后输入视频链接 → 查价（按时长/分辨率）→ 提交订单 → 获得夸克下载链接。无需您手动复制链接。见 [客户自助网站](#客户自助网站) 与 [负载均衡](#负载均衡)。

---

### 2. 夸克云盘

| 项目 | 说明 |
|------|------|
| **夸克账号** | 用于存储并分享视频的夸克网盘账号。 |
| **登录凭证** | 夸克未提供正式开放 API，本系统通过 **Cookie** 或社区实现的 **Token** 上传。您需要：<br>• 浏览器登录 [夸克网盘](https://pan.quark.cn)，按项目内 `docs/夸克Cookie获取.md` 获取 Cookie；<br>• 或使用支持 Token 的第三方库（若后续集成）。 |
| **存储空间** | 确保账号有足够空间存放视频文件。 |

---

### 3. 运行环境

| 项目 | 说明 |
|------|------|
| **Python** | 建议 3.10+，用于运行下载服务与助手。 |
| **FFmpeg** | 用于合并音视频（yt-dlp 常用）。请安装并加入 PATH：[FFmpeg 官网](https://ffmpeg.org/download.html)。 |
| **yt-dlp** | 通过 `pip install yt-dlp` 安装，用于多平台视频下载（B站、抖音等）。 |
| **磁盘空间** | 下载临时目录需要足够空间存放原视频，处理完成后可删除或保留由您配置。 |

|------|------|

## 系统架构概览

```
[闲鱼客户] ←→ [闲鱼平台] ←→ [助手] ←→ [下载与上传系统]
                    ↑              ↑
                    |              +-- 提交视频链接
                    |              +-- 接收云盘链接并回发客户
                    |
              [您可对接的闲鱼自动化/或人工复制]
```

- **助手**：接收「客户发来的视频链接」、调用下载系统、把「云盘链接」回传（或提供给闲鱼侧发送给客户）。
- **下载与上传系统**：解析链接 → yt-dlp 下载 → 上传夸克云盘 → 返回云盘分享链接。

## 快速开始

1. 安装依赖：`pip install -r requirements.txt`
2. 配置 `config/config.yaml`（下载目录、夸克 Cookie 等）
3. 获取夸克 Cookie：见 `docs/夸克Cookie获取.md`
4. 启动：先启动「下载与上传服务」，再启动「助手」；或使用 `scripts/run_all.bat`（Windows）
5. 测试：用 `tests/` 下脚本或 Web 管理页提交一条 B 站链接，检查是否下载并上传到夸克并返回链接

详细步骤见 [配置与运行](#配置与运行) 和 [测试](#测试)。

## 配置与运行

1. **配置文件**：复制 `config/config.yaml.example` 为 `config/config.yaml`，按需修改；夸克 Cookie 见 `docs/夸克Cookie获取.md`。
2. **安装依赖**：在项目根目录执行  
   `pip install -r requirements.txt`  
   并确保已安装 **FFmpeg**（用于合并音视频）。
3. **启动顺序**：  
   - 先启动「下载系统」：`python -m src.system.server`（或 `scripts\run_system.bat`），默认端口 **8766**。  
   - 再启动「助手」：`python -m src.assistant.app`（或 `scripts\run_assistant.bat`），默认端口 **8765**。  
   - 也可运行 `scripts\run_all.bat` 一次打开两个终端。
4. **使用方式**：  
   - 打开浏览器访问 **http://127.0.0.1:8765**，在页面输入客户发来的视频链接并提交，即可得到云盘链接（未配置夸克时可勾选「仅下载测试」）。  
   - 或调用助手 API：`POST http://127.0.0.1:8765/order`，Body：`{"video_url":"https://...", "order_id":"可选", "skip_quark": false}`。
5. **客户自助网站**（可选）：  
   - 启动「自助网站」：`python -m src.store.app`（或 `scripts\run_store.bat`），默认端口 **8770**。  
   - 将 **http://你的域名或IP:8770** 发给闲鱼客户；客户输入视频链接即可查价、下单并获取夸克链接。  
   - 定价在 `config/config.yaml` 的 `store.pricing` 中配置（按时长、分辨率加价）。

## 客户自助网站

- **用途**：闲鱼客户打开链接后自助完成「输入视频链接 → 查价 → 提交订单 → 获得夸克下载链接」，您无需逐个复制链接。
- **定价**：按视频**时长**与**分辨率**计费，在 `config.yaml` 的 `store.pricing` 中可调。
- **启动**：`python -m src.store.app` 或 `scripts\run_store.bat`，默认访问 **http://127.0.0.1:8770**。
- **公网**：部署到服务器并开放 8770 端口（或反向代理），将公网 URL 发给客户即可。

## 负载均衡

- **单机**：当前自助网站与助手均单进程即可运行，订单在内存中排队处理。
- **多实例**：若需多机/多进程分担请求，可在前方加 **Nginx/云负载均衡** 做 HTTP 分流；注意同一订单的「提交」与「轮询状态」需落在同一实例（可用会话保持 / sticky session），或后续将任务状态存 Redis，多实例共享状态。

## 关于夸克上传

夸克网盘无官方开放 API，当前 `src/quark/client.py` 中的上传与分享接口为基于社区逆向的示例实现，**实际请求格式可能随夸克网页版更新而变动**。若上传失败，可：

- 按 `docs/夸克Cookie获取.md` 确认 Cookie 有效；
- 参考开源项目 [quark-auto-save](https://github.com/Cp0204/quark-auto-save) 等更新接口或改用其 API；
- 暂时使用「仅下载」模式，手动将 `downloads/` 下文件上传到夸克并复制链接给客户。
